# ⚙️ Installation

## 1️⃣ Clone Project

```bash
git clone https://github.com/yourusername/chat-app.git
```

---

## 2️⃣ Install Backend Packages

```bash
cd public
npm install
```

---

## 3️⃣ Install Frontend Packages

```bash
cd client
npm install
```

---

# ▶️ Run Backend

```bash
cd public
npm run dev
```

Backend running on:

```bash
http://localhost:5000
```

---

# ▶️ Run Frontend

```bash
cd client
npm run dev
```

Frontend running on:

```bash
http://localhost:5173
```

---

# 🔑 Environment Variables

Create `.env` inside `public/`

```env
PORT=5000
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
```
